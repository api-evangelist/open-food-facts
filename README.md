Open Food Facts is a collaborative, free and open database of food products from around the world, built by everyone for everyone. Anyone can scan a barcode and contribute product data, and the whole database is published under the Open Database License so it can be re-used for any purpose. The project publishes a documented public HTTP API for reading and writing product data, plus a family of companion services — Open Prices, Search-a-licious full-text search, the Folksonomy engine, facet knowledge panels and the NutriPatrol moderation API — alongside official SDKs in Python, JavaScript, Dart, Ruby, PHP and Go.

**Areas:** Food · Nutrition · Open Data · Product Data · Barcodes · Taxonomy · Prices · Search · Food and Beverage

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Open Food Facts: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
